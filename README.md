# Mi Rincón Gamer 🎮

Proyecto web desarrollado como parte de mis prácticas de programación, enfocado en el diseño front-end y estilos modernos con temática de videojuegos.

## 🛠️ Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

## 🚀 ¿Qué incluye?
- Diseño responsivo.
- Animaciones y efectos visuales personalizados.
- Interactividad con botones.
